# Web Storage Manager

<SupportedPlatforms
    platforms={[Platform.Android, Platform.iOS, Platform.macOS]}></SupportedPlatforms>

The `WebStorageManager` class implements a singleton object (shared instance) which manages the web storage used by `WebView` instances.

On Android, it is implemented using the [WebStorage](https://developer.android.com/reference/android/webkit/WebStorage.html) class.
On iOS and macOS, it is implemented using [WKWebsiteDataStore.default()](https://developer.apple.com/documentation/webkit/wkwebsitedatastore) instance.

:::info Note for iOS
  Available from iOS 9.0+.
:::
## 1. What is Web Storage Manager
The **Web Storage Manager** in flutter_inappwebview is a centralized interface to manage web storage data generated by web pages loaded in the WebView. It includes:
- LocalStorage: Persistent key-value storage.
- SessionStorage: Temporary key-value storage (cleared when the session ends).
- IndexedDB: A NoSQL database for structured data.
- WebSQL: A deprecated SQL-based database (still supported in some browsers).
- Cookies: Small pieces of data stored by websites.

## 2. Storage Mechanisms
**a. LocalStorage & SessionStorage**
- Technology: Uses the Web Storage API (`window.localStorage` and `window.sessionStorage` in JavaScript).
- Storage:
    - Android: Stored in an SQLite database at `/data/data/<package_name>/app_webview/Default/LocalStorage.`
    - iOS: Stored in the app's sandboxed `Library/Caches/<BundleID>/WebKit/WebsiteData/LocalStorage.`
- Persistence:
    - LocalStorage: Persists until explicitly cleared.
    - SessionStorage: Cleared when the WebView session ends.
- Limit: Typically 5-10 MB per origin (varies by browser/WebView).
** b. IndexedDB**
- Technology: A low-level NoSQL API for storing large amounts of structured data.
- Storage:
    - Android: SQLite database at `/data/data/<package_name>/app_webview/Default/IndexedDB.`
    - iOS: Binary files in `Library/Caches/<BundleID>/WebKit/WebsiteData/IndexedDB.`
- Persistence: Survives app restarts.
- Limit: Up to 50% of total disk space (browser-dependent).
**c. WebSQL**
- Technology: A deprecated SQL-based API (still supported in WebView).
- Storage: SQLite database files (similar path to IndexedDB).
- Limit: Defaults to 5 MB per origin (can be increased via configuration).
**d. Cookies**
- Technology: HTTP cookies managed via `CookieManager`.
- Storage:
    - Android: Stored in `SharedPreferences` or a dedicated cookie database.
    - iOS: Uses `NSHTTPCookieStorage`.
- Persistence: Controlled by `expires` attribute or session-only.
## Basic Usage

On Android, the `WebStorageManager` class is used to manage the JavaScript storage APIs provided by the WebView.
It manages the Application Cache API, the Web SQL Database API and the HTML5 Web Storage API.

On iOS and macOS, the `WebStorageManager` class represents various types of data that a website might make use of.
This includes cookies, disk and memory caches, and persistent data such as WebSQL, IndexedDB databases, and local storage.

Example:
```dart
// get the WebStorageManager instance
WebStorageManager webStorageManager = WebStorageManager.instance();

if (!kIsWeb) {
  if (defaultTargetPlatform == TargetPlatform.android) {
    // if current platform is Android, delete all data.
    await webStorageManager.deleteAllData();
  } else if (defaultTargetPlatform == TargetPlatform.iOS ||
      defaultTargetPlatform == TargetPlatform.macOS) {
    // if current platform is iOS or macOS, delete all data for "flutter.dev".
    var records = await webStorageManager.fetchDataRecords(
        dataTypes: WebsiteDataType.values);
    var recordsToDelete = <WebsiteDataRecord>[];
    for (var record in records) {
      if (record.displayName == 'flutter.dev') {
        recordsToDelete.add(record);
      }
    }
    await webStorageManager.removeDataFor(
        dataTypes: WebsiteDataType.values, dataRecords: recordsToDelete);
  }
}
```
